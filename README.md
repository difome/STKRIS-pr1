# Grade Calculator (STKRIS PR #1)

A console application to calculate a student's average grade and convert it to the ECTS grading scale. 
Built with Python 3.11+ and Git feature branching.

## Features
- Validates user input (protects against letters and negative numbers).
- Calculates the average score for 3 subjects.
- Converts the result to an ECTS grade (A-F).

## How to run

Use `uv` to run the application:

```bash
uv run main.py
```
